## 4. 상담 신청 폼이 메일로 오게 하려면

`functions/api/contact.js` 가 폼 내용을 이메일로 보내는 서버 역할을 합니다. Cloudflare Pages가 자동으로 인식하므로 따로 설정할 것은 없고, 환경변수 세 개만 넣으면 됩니다.

1. https://resend.com 에서 무료 계정을 만들고 API 키를 발급받습니다. (월 3,000통 무료)
2. Cloudflare Pages 프로젝트 → **Settings → Environment variables** 에 추가합니다.
   - `RESEND_API_KEY` : 발급받은 키
   - `CONTACT_TO` : 상담 내용을 받을 회사 이메일
   - `CONTACT_FROM` : 발신 주소. 도메인 인증 전에는 `onboarding@resend.dev` 로 테스트할 수 있고, 인증 후에는 `지유공간개발 <contact@회사도메인>` 형식으로 바꿉니다.
3. 다시 배포(Retry deployment)하면 적용됩니다.

5장의 데이터베이스(D1)를 연결하면 메일 설정이 없어도 상담은 관리자 화면 「상담 문의」에 저장됩니다. 메일 설정과 데이터베이스가 둘 다 없을 때만 방문자의 메일 앱이 열리면서 `site-config.js` 의 `email` 주소로 내용이 채워진 메일이 만들어집니다.
Formspree 같은 다른 서비스를 쓰고 싶으면 `site-config.js` 의 `formEndpoint` 값만 그 주소로 바꾸면 됩니다.

## 5. 관리자 화면 · 방문 통계 · 회원 기능

`https://guspace.kr/admin/` 에서 방문자 수, 페이지별 방문, 체류시간, 인기 정보, 유입 경로, 클릭·전환, 상담 문의, 회원 목록을 볼 수 있습니다.
방문 기록은 외부 분석 도구 없이 이 홈페이지의 서버(Cloudflare Pages Functions)와 데이터베이스(Cloudflare D1)에만 저장됩니다.

### 처음 한 번만 하는 설정 (Cloudflare 대시보드에서, 10분 정도)

표는 첫 요청이 들어올 때 자동으로 만들어지므로 SQL이나 터미널 작업은 필요 없습니다.

1. **데이터베이스 만들기** — Cloudflare 대시보드 왼쪽 메뉴 **Storage & Databases → D1 SQL Database** (또는 상단 검색창에 `D1`) → **Create Database**
   - 이름: `guspace-db` (다른 이름이어도 됩니다)
   - Location: 고를 수 있으면 **Asia-Pacific** 를 권합니다.
2. **홈페이지에 연결하기** — **Workers & Pages** → 이 홈페이지 프로젝트 → **Settings → Bindings → Add → D1 database**
   - Variable name: **`DB`** (반드시 대문자 DB)
   - D1 database: 1번에서 만든 `guspace-db`
3. **관리자 비밀번호 정하기** — 같은 프로젝트 **Settings → Variables and Secrets → Add**
   - Type: **Secret**, Variable name: **`ADMIN_PASSWORD`**, Value: 12자 이상으로 정한 비밀번호
   - 비밀번호를 바꾸면 이미 로그인한 관리자는 모두 로그아웃되고 새 비밀번호로 다시 들어오게 됩니다.
4. **다시 배포** — **Deployments** 에서 최신 배포 오른쪽 메뉴(…) → **Retry deployment**
5. `https://guspace.kr/admin/` 에 들어가 비밀번호로 로그인합니다. 설정이 덜 되어 있으면 무엇이 빠졌는지 화면에 안내가 나옵니다.

> 미리보기 배포(Preview)에서도 쓰려면 2·3번을 Preview 환경에도 똑같이 넣어 주세요. 운영(Production)만 쓰면 Production에만 넣으면 됩니다.

4장의 Resend 환경변수까지 넣으면 상담 접수 시 담당자 메일 알림과 회원 **비밀번호 찾기 메일**이 함께 동작합니다. 메일 설정이 없어도 상담은 관리자 화면 「상담 문의」에 모두 쌓입니다.

### 알아 두실 것

- **관리자 본인의 방문은 통계에서 빠집니다.** 관리자로 로그인해 있는 동안은 자동으로 빠지고, 로그아웃한 뒤에도 회사 PC 방문을 빼려면 「설정 → 이 브라우저 방문 제외」를 켜 두세요. 설치 확인은 다른 브라우저나 휴대폰으로 홈페이지를 열어 보면 됩니다.
- **방문자 수는 브라우저 기준입니다.** 같은 사람이 PC와 휴대폰으로 오면 두 명으로 셉니다. 검색 로봇과 자동 접속은 걸러 냅니다.
- **검색어는 일부만 보입니다.** 네이버·구글이 대부분 검색어를 넘겨주지 않기 때문입니다. 전체 검색어는 네이버 서치어드바이저와 구글 서치콘솔에서 확인하세요.
- **블로그·SNS·문자에 링크를 걸 때**는 「유입 경로 → 캠페인 링크 만들기」로 만든 주소를 쓰면 게시물별 유입과 상담 전환을 따로 볼 수 있습니다.
- **비용**: Cloudflare 무료 요금제 한도(D1 저장 5GB, 하루 읽기 500만 행 · 쓰기 10만 행, Functions 하루 10만 요청) 안에서 이 규모의 회사 홈페이지는 충분히 운영됩니다.
- **개인정보**: 방문 통계에는 IP 주소·이름·연락처를 저장하지 않습니다. 회원가입과 이용 통계가 추가되면서 `privacy.html` 개인정보처리방침과 `member/terms.html` 이용약관을 함께 고쳤습니다. 국외 이전(Cloudflare·Resend) 항목을 포함해 내용을 한 번 검토해 주시고, 개인정보 보호책임자 연락처를 채워 주세요.

### 회원 기능

- 상단 메뉴의 「로그인」에서 가입·로그인할 수 있고, 로그인하면 「마이페이지」로 바뀝니다.
- 회원이 상담을 신청하면 이름·연락처가 자동으로 채워지고, 진행 상태를 마이페이지에서 확인할 수 있습니다(관리자가 상담 문의에서 바꾼 상태가 그대로 보입니다. 내부 메모는 보이지 않습니다).
- 비밀번호는 복원할 수 없는 방식(PBKDF2)으로 암호화해 저장합니다. 비밀번호 찾기는 Resend 메일 설정이 있어야 동작합니다.
- 회원 페이지는 `tools/make_member_pages.py` 로 만듭니다. 상단 메뉴나 하단을 고친 뒤 이 스크립트를 다시 실행하면 회원 페이지에도 반영됩니다.

## 7. 내용 수정 방법

- 문구 수정: 각 HTML 파일을 열어 해당 문장을 고치면 됩니다. 페이지마다 상단 메뉴와 하단은 같은 구조라 같이 손보는 것이 좋습니다.
- 색 바꾸기: `assets/css/site.css` 맨 위 `:root` 의 `--point`(포인트 그린), `--ink`(네이비) 값을 바꾸면 사이트 전체에 적용됩니다.
- 사진 교체: `assets/img/` 에 같은 이름의 WebP 파일을 넣습니다. 큰 파일(가로 1600px)과 `-800` 이 붙은 작은 파일 두 장이 한 쌍입니다.
- 글꼴: 본문은 Pretendard, 제목은 Noto Serif KR입니다. 두 파일 모두 한글 상용 2,350자(KS X 1001)와 라틴 문자·숫자·기호를 담아 새로 만든 것이라, 일상적인 한국어 문장은 모두 정상적으로 나옵니다. 다만 "뷁"처럼 표준 상용 한글에 없는 희귀 음절을 새로 넣으면 그 글자만 시스템 기본 글꼴로 보입니다. 그런 글자가 필요하면 알려주시면 글꼴을 다시 만들어 드립니다.
- 사진은 사이트 안에서 한 장을 한 번만 쓰도록 배치했습니다. 새로 넣을 때도 같은 사진이 두 페이지에 나오지 않게 해 주세요.

## 9. 내용 관련 원칙

- 인사이트 글은 `tools/content.py` 에 본문이, `tools/faq.py` 에 문답이 들어 있습니다. 글을 추가하거나 고친 뒤 `python3 tools/make_insights.py` 를 실행하면 목록과 구조화 데이터까지 다시 만들어집니다. 글을 직접 HTML로 고치셔도 되지만, 그 경우 스크립트를 다시 돌리면 덮어쓰기되니 주의하십시오.
- 사이트의 뼈대는 "건물관리(FM·PM) → 공실·임차사 관리 → 공실개발·자산가치 증대"의 세 층 구조입니다. 새 페이지나 문구를 추가할 때도 이 순서 안에서 자리를 잡으면 전체 메시지가 흐트러지지 않습니다.
- 자산관리 PM 페이지의 월간 보고서 화면은 예시이며, 숫자는 실제 건물 자료가 아닙니다. 실제 보고서 양식이 정해지면 그 화면으로 바꾸는 것을 권합니다.

- 지유코퍼레이션 실적(37개 동, 195,000평, 12개 분야 SOP)은 모두 "연계사 기준"으로 표기했습니다. 지유공간개발의 직접 수행 실적은 프로젝트가 생기는 대로 별도로 추가하면 됩니다.
- 스마트 빌딩, 빌딩 인텔리전스 등 기획 단계의 사업은 "준비 중" 또는 "방향"으로만 적었고, 플랫폼이나 시스템을 이미 보유한 것처럼 쓰지 않았습니다.
- 시공은 등록 전문업체가 맡고 지유공간개발은 발주자 편 PM만 한다는 점, 진단이 유료라는 점을 관련 페이지마다 밝혔습니다.
